觀察 Dorico Pro 6 的介面與人因設計，對照 Score Arranger 現況，挑出值得借鑑的方向。 勾選你要的，底部「複製決策摘要」貼回給我即可開工。

2026-06-06 · 基於 Dorico 6 官方/Scoring Notes 評測 + 你目前 0.1.96 介面截圖與程式碼

📌 先講結論：我們其實已經走在 Dorico 路線上

  • ModeBar（設定／分析／改編／移植／修復／匯出）— 程式碼註解就寫著「借鑑 Dorico 的 mode-based workflow」，這正是 Dorico 五大 mode（Setup/Write/Engrave/Play/Print）的精神。
  • IssuePanel ≈ Dorico 6 Proofreading 面板 — Dorico 6 的旗艦新功能「校對面板」做的事（背景偵測、分類列出問題、點擊跳到位置），你早就有了。這是強力的方向驗證。
  • 成熟的 design token 系統 — index.html 已有 light/dark 雙主題、gold accent、elevation／easing／radius／glass tokens、語意化 error/warning/success。基礎比多數 Electron app 紮實。

所以這不是「從零美化」，而是精修 + 補上 Dorico 幾個招牌人因。

🔭 Dorico Pro 6 我觀察到、值得偷的人因設計

  • 克制的 chrome：頂部極簡，控制項收進情境面板，把畫面讓給譜。
  • 情境感知 Properties 面板（底部）：只顯示「目前選取物件」相關的屬性 — 漸進揭露，降低認知負荷。
  • Jump bar / 命令面板：鍵盤驅動、搜尋所有命令（類似 VS Code ⌘K）。
  • Proofreading 呈現細節：分類色碼（譜號／力度／調號／反覆…）、面板圖示上的紅色數量徽章、點擊後動畫箭頭/方框精準定位問題。
  • Fill View（6 新增）：音樂填滿視窗寬度、垂直堆疊系統、看到最多小節。
  • Status bar：底部持續顯示小節範圍、小節號、timecode。
  • 更小的 handles、可拖曳 popover（帶錨點）、View Options 統整對話框。
⚖️ 反方論點（先說清楚）：Score Arranger 是智慧改編 + 教學工具，不是專業排版軟體。 Dorico 的複雜度有一半是給排版/出版用的（Engrave ruler/grid、front matter…），照搬會稀釋你的定位。 我們該偷的是「降低認知負荷」與「教學友善」那一面，不是把功能堆到跟 Dorico 一樣多。下面卡片已照此篩選。

Path A — 視覺精修 低風險，多數我可立即做，幾天內

不改架構，只收斂視覺噪音、補上一致性。投報率最高、風險最低。

A1收斂頂部 chrome，讓譜面呼吸🎯 建議
目前頂部疊了 4–5 條橫列（Toolbar＋TabStrip＋ModeBar＋子工具列＋各面板播放列），譜被擠到下半。 合併/收納次要控制（如把播放列收進面板標頭、次要按鈕進 overflow 選單），騰出垂直空間。Dorico 最明顯的氣質就是「乾淨的頂部」。
借鏡：Dorico 克制的 chrome
衝擊 高投入 中風險 低可立即做
A2統一面板標頭 + 8px 間距節奏 + 克制 accent🎯 建議
所有面板用一致的標頭樣式（標題＋摺疊鈕＋次要動作靠右）、統一 padding 走 8px 網格、 把 gold accent 留給「主要動作/當前狀態」而非到處點綴（Dorico 用色極省）。立刻顯得更專業。
借鏡：Dorico 的視覺一致性與克制用色
衝擊 中投入 中風險 低可立即做
A3持久狀態列 (Status bar)
底部加一條持續資訊列：目前小節號、選取資訊、改編品質摘要、引擎狀態。 Dorico 招牌之一，也順手解決「引擎在做什麼」的可見性。
借鏡：Dorico Status bar
衝擊 中投入 中風險 低可立即做
A4字級階層 + 圖示一致化
收斂字級到 3–4 個尺度、統一圖示風格與描邊粗細、行高與對齊微調。細節層級的質感升級。
借鏡：Dorico 的排版紀律
衝擊 低投入 低風險 低可立即做

Path B — 人因互動 Dorico 招牌，中投入，1–2 週

真正拉開體驗差距的部分。挑對教學/改編工作流有感的做。

B1命令面板 / Jump bar（⌘K 搜尋所有命令）🎯 建議
一個 ⌘K 喚出的搜尋框，輸入即可跳到任何 mode／套用任何操作／開任一面板／搜曲庫。 對熟手是巨大效率躍升，對新手是「找得到功能」的安全網。功能多但入口分散的 app 最該補這個。
借鏡：Dorico Jump bar
衝擊 高投入 中風險 低
B2IssuePanel → Proofreading 升級🎯 建議
把現有 IssuePanel 補上 Dorico 6 的呈現細節：問題分類色碼（音域／弓法／聲部範圍／可演奏性…）、 面板上的數量徽章、點擊時譜面動畫定位（你已有 flash highlight，再強化）。核心面板，直接受益。
借鏡：Dorico 6 Proofreading 面板
衝擊 高投入 中風險 低
B3情境 Properties 區（依選取顯示）
點選一個小節/音符/聲部時，底部出現「只跟它有關」的屬性與操作（移調、改演奏法、重分配…）， 取代到處找面板。Dorico 漸進揭露的核心，但要小心別跟現有面板重複。
借鏡：Dorico Properties 面板
衝擊 中投入 高風險 中
B4Fill View（一鍵塞滿最多小節）
一個檢視模式：譜面填滿視窗寬度、垂直堆疊、不用橫向捲動就看到最多小節。 你已有 ribbon/zoom，這是補一個「總覽」視角。
借鏡：Dorico 6 Fill View
衝擊 中投入 中風險 中

Path C — 大結構 大投入，建議先緩

方向正確但成本高、且部分對「改編工具」定位可能 overkill。列出來讓你知道有這條路。

C1完整 Properties-panel 範式重構
把所有編輯操作統一收斂成「選取 → 底部屬性面板」的單一範式（B3 的全面版）。體驗最一致，但要動很多既有面板，風險最高。
借鏡：Dorico 整體互動範式
衝擊 高投入 很高風險 高
C2Engrave 級精準（ruler / grid）
Dorico 6 在 Engrave mode 加了尺規與格線。對「出版排版」有用，但 Score Arranger 是改編工具、最終常匯出到 MuseScore/Dorico 細修 — 自己做排版精修可能不划算。傾向不做。
借鏡：Dorico 6 Engrave ruler/grid
衝擊 低投入 很高風險 中

🎯 我的建議起手式

  • 先做 Path A 全部（A1–A4）— 低風險、我可立即開工，幾天內就讓整體質感升一級。A1 收斂頂部 chrome 衝擊最大。
  • 接著 B2（Proofreading 升級）+ B1（命令面板） — 一個強化核心面板、一個補關鍵人因，兩個都是高 ROI。
  • B3/B4 看完上面再決定；Path C 先緩（C2 傾向不做）。
