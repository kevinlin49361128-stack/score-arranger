📌 取樣庫：VSCO2 CE 幾乎是唯一正解

  • VSCO2 Community Edition = CC0 公共領域（零授權摩擦，連 attribution 都免）、Versilian 用專業器材重錄、含 violin/viola/cello/bass、50+ articulations（pizzicato、spiccato、tremolo、mute…），GitHub 開源 (WAV/SFZ)。對你（GPL 開源 + 教學）是完美匹配。
  • 其他庫都更麻煩：Iowa MIS（公共領域、音質最高但原始未處理、超大）、Sonatina SSO（要 attribution、音色拼湊不一致）、Virtual Playing Orchestra（混多庫、要 attribution）。

所以「選哪個庫」我直接建議 VSCO2 CE。下面庫卡片預設幫你勾好它，其餘列出只為完整。

⚖️ 先講清楚工程量與反方：這是整個音質工程最大的一塊 —— 要把 WAV 轉成 web 友善的逐音檔、走 corpus CDN 懶載入（不灌 DMG）、寫多 articulation sampler bank、把引擎已標的演奏法（pizz/staccato…）路由到對應樣本（B2）、加力度層（B3）。預估數天到一週。 反方：Score Arranger 是改編工具，播放是預覽/陪練不是成品 —— 但你的客群是教學/陪練，音質對他們有實際價值，且這是你主動選的方向。重點是範圍別爆：下面預設配置刻意走「明顯變好但容量可控」。

② 範圍取捨 這才是真正要你拍板的（決定容量/真實度/工時）

演奏法 — 每多一種 = 多一組樣本 + B2 切換邏輯。引擎已會標演奏法，差「有對應樣本可播」。

A1Sustain / arco（長弓持續音）🎯 必備
基礎音色，取代現在的單一線上樣本。這條一定要。
基礎
A2Pizzicato（撥弦）🎯 建議
與長弓聽感差異最大的演奏法，巴洛克/古典常用。投報率最高的第二組。
高對比+1 組
A3Staccato / spiccato（短音）🎯 建議
快速音群、斷奏段落用持續音播會「黏成一片」；短音樣本立刻對。
快速段有感+1 組
A4Tremolo（震音）
浪漫派織體用。用到的曲目較少，可後補。
+1 組用量較少
A5Con sordino（弱音器）
柔色段落。錦上添花，優先序最低。
+1 組錦上添花

力度層（B3） — 真弦樂大聲不只更響、是換了音色。現在只有音量差（A1 加了亮度濾波部分補償）。

V22 層（弱 / 強）🎯 建議
最佳 CP 值：力度跨過門檻就換音色，明顯更真，容量只 ×2。
CP 值最佳容量 ×2
V33 層（弱/中/強）
更細緻的漸層，但容量 ×3 + crossfade 邏輯更複雜。要不要看你對容量的容忍。
最真容量 ×3
V11 層（維持現狀 + 亮度濾波）
不加力度層，靠 A1 的亮度濾波撐。最省，但這就放棄了 B3 的主要價值。
最省放棄 B3

容量控制 — 決定 CDN 流量 + 載入速度。Tone.Sampler 會自動內插缺的音。

S1疏取樣（每 3 半音 1 個）+ mp3 ~128k🎯 建議
Sampler 內插中間音，聽感幾乎無損但容量砍到 1/3。web 交付最務實。
容量小載入快
S2密取樣（每半音）+ 高位元率
最忠實、無內插假象，但容量數倍、首次載入慢。對「預覽/陪練」定位可能過頭。
最忠實容量大
S3走 corpus CDN 懶載入（不灌 DMG）🎯 建議
沿用你既有的線上 corpus CDN 基礎設施，按樂器×演奏法用到才載，App 體積不變。
不灌 DMG復用既有 CDN

🎯 我建議的起手配置

VSCO2 CE · 演奏法 = 長弓 + 撥弦 + 短音（3 種）· 2 力度層 · 疏取樣 mp3 + CDN 懶載入。

  • 這組「明顯質變但容量可控」：3 演奏法 × 2 力度層 × 疏取樣 × 4 弦樂器，估計每樂器幾 MB、總計可控，且全走 CDN 不進安裝檔。
  • 之後想加 tremolo / 弱音器 / 第 3 力度層都能增量補，不用重做架構。
  • 實作順序：先做 sampler bank 基礎設施 + 長弓換 VSCO2（立刻聽到底色變好）→ 接 B2 演奏法切換 → 加 B3 力度層。每階段出 build 給你聽。
