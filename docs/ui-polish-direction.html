市場觀察 + 現況設計系統盤點 + 我的美感方向 + 可執行的 A-sprint 切片。這份文件本身就用我提議的視覺語言（暖金古典 + 玻璃層次）做 —— 你看到的就是我要落地的調性。

01市場觀察：競品在做對什麼

挑了同領域 5 個代表，萃取「給專業/古典客群」的共通設計法則。

App它做對的事給我們的啟示
Dorico「預設就漂亮」—— 自動排版、跨平台一致，開箱即美。預設美感 > 可調整性。使用者不該為了好看去調設定。
MuseScore 4面板可堆疊 + 分頁切換；明/暗/高對比主題 + accent 色自選；Inspector 重整為 Properties。面板收斂成「分頁堆疊」；主題 + accent 是基本盤（我們已有暖金）。
StaffPadiPad-native 的 premium 觸感；動態/速度可用手勢「畫」出來。直接操作（direct manipulation）+ 觸感回饋 = 高級感來源。
Soundslice細節工藝：滑音線微傾斜、刻意穿過譜線以利閱讀。質感藏在「小到沒人會列為功能」的渲染細節裡。
Sibelius（反面教材）以「介面設計差、雜亂」聞名於工程圈。少即是多。把面板/按鈕藏起來，需要時才浮現。
一句話總結：古典/專業客群要的是 Dorico 的「預設美」+ Soundslice 的「細節工藝」+ 反 Sibelius 的「不雜亂」。我們的暖金紙感身分已經贏在起跑點 —— 跟一票冷色 IDE 風的記譜軟體區隔開了，要做的是「深化」不是「重來」。

03我的美感方向（這就是調性）

沿用你的暖金紙感身分，補上三件讓它「貴起來」的事：真玻璃、統一立體層次、彈性緩動。下面是實物 demo。

① 真・玻璃質感（backdrop-filter: blur）

這張卡用的就是 blur(18px) saturate(1.3) + 暖金細邊 + 三層陰影。所有浮動面（popover / 對話框 / 混音台 / 浮動播放列）都套這層，背景的譜面會柔柔透出來 —— 空間層次立刻出來。

04A-Sprint：勾你要的（0.1.90 候選）

點卡片切換。每項標了 價值 / 工 / 風險。🎯 = 我建議納入。

✓
基礎層：設計 token 化（glass / elevation / spring / radius）🎯 地基
在 index.html 加：玻璃 utility（真 blur）、三階 elevation、spring/refined 緩動、radius scale。純新增 CSS，零行為風險。後面每一項都站在這層上。
價值 高（解鎖其餘）工 小風險 極低
✓
把玻璃 + 立體層次套到既有浮動面🎯 高 CP
混音台 popover、所有對話框、coachmark、NL 面板 → 改用玻璃 + elevation。視覺一致度 + premium 感立刻跳一階，改的是現成元件的容器樣式。

✓
行內 issue 氣泡 + Quick Fix🎯 主菜
小節掛 ⚠ marker（重用既有 getMeasureBox bbox），hover 浮玻璃氣泡帶「移八度 / 省略音」等就地修。Issue 面板保留為總覽，但日常操作走氣泡 → 大幅減少雜亂（反 Sibelius）。

✓
微互動精修（hover/press 觸感 + 勾選 spring）
按鈕 hover 微浮起、press 回彈、勾選框 spring、tab 切換底線滑動。全用新緩動 token，零邏輯改動，純「手感」升級。
價值 中工 小風險 極低

套用 fix 時，音符從舊位置平滑滑到新位置（而非瞬切/閃光）。報告點名的「靈性」細節，但要追 OSMD 音符座標差，較脆。
價值 中工 中–大風險 中–高
✓
