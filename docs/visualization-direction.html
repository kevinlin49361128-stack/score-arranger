視覺化方向決策

Score Arranger · 2026-06-04 · 點卡片勾選想做的，底部「複製決策摘要」回傳給我

準則：新視覺化的門檻是「樂譜看不到、但改編／教學真的需要」。eye-candy（純好看、不 actionable）一律降級。

已有的視覺化（別重做）： 難度熱圖 issue ⚠ 標記 A/B diff 高亮 指板衝突模擬 修復時間軸 scrubber 品質雷達 主旋律路線時間軸 練習進度

🎯 建議 — 服務改編／教學的真實 gap

✓
聲部即時音量表 (per-voice VU) 🎯 建議工程 S

播放時每個聲部一條小音量條，即時跳動。

填補：耳朵聽到「低音太小聲」→ 眼睛也看得到是哪一軌 → 直接去既有混音台調。

＋ actionable、接既有混音台、教學上「平衡」具象化　－ 每樂器一個 AnalyserNode

✓
音域帶狀圖 (tessitura bands) 🎯 建議工程 S–M

每樂器一條橫帶：實際用到的音域 vs 舒適／可演奏音域，超出處標紅。

填補：可演奏性一眼看完（正是 issue panel 在逐一抓的東西），資料同源、不必重算。

＋ 直接服務可演奏性、跟引擎音域檢查同源　－ 要設計緊湊版面

✓
即時和聲讀出 (播放中顯示和弦／羅馬數字) 🎯 建議工程 M

游標移動時，同步顯示當下和弦名 / 羅馬數字 / 級數。

填補：教學金礦——學生看著和聲走向學；接既有 A1b 羅馬數字分析，能力已在引擎裡。

＋ 教學價值高、複用既有和聲分析　－ 和聲分析要對齊播放時間軸

🤔 較大賭注 / 中性 — 值得但要想清楚

✓
鋼琴捲軸 / 音高-時間視圖 (piano-roll) 🤔 大賭注工程 L

橫向「音高 × 時間」，所有聲部用顏色區分，跟播放游標同步。

填補：聲部交叉、音域重疊、織體密度——這些樂譜不易一眼看出，改編者真的需要。但工程最大。

＋ 補記譜的盲點、改編者真需求　－ 要從 IR 渲同步 canvas + 對齊游標，工程大

✓
力度／表情曲線 (dynamics curve) 🤔 中性工程 S–M

疊在譜面或時間軸上的一條力度輪廓線，看 phrasing 起伏。

＋ 看表情輪廓　－ 價值中等、錦上添花，記譜已有強弱記號

✓
織體密度時間軸 (texture density) 🤔 中性工程 S

沿時間顯示「同時發聲幾個音」，看編配的疏密／留白。

＋ 看編配密度　－ 跟既有難度熱圖部分重疊

❌ 不建議 — eye-candy，不服務工作

✓
音訊波型 (waveform / 示波器) ❌ 不建議工程 S

master 輸出的即時波型動畫。

＋ 動感、demo 截圖吸睛　－ 合成音波型平淡、不 actionable、樂譜+游標已是更好的視覺、與「克制」美感衝突

✓
頻譜長條 (spectrum / FFT bars) ❌ 不建議工程 S

頻率長條跳動（同波型一類）。

－ 同波型，對改編工作零幫助

🌊 連續流動視覺化 — 跟著播放游標捲動

架構洞察： 與其各做各的，先做一條 播放時間軸流動條（隨游標捲動的橫條）， 每種連續視覺化都是它的一條 lane（可開關）。第一條做完，後面每加一條成本極低 —— 省力又不雜亂。 建議：流動條 + 2-3 條有意義 lane 就夠，再多是雜訊。
✓
時間軸流動條 — 基礎元件 (prerequisite) 🎯 先做工程 M

隨播放游標捲動的橫條，可掛多條 lane。下面每個連續視覺化都跑在它上面。

填補：一次投資、後續每條連續 lane 都變便宜。先有它，下面才好加。

✓
和聲張力曲線 (tension curve) 🎯 建議lane

不協和度／調性張力沿時間起伏的曲線。

填補：看 cadence 的「張力→解決」、高潮在哪。接既有和聲分析，教學金礦。

＋ 教育價值高、複用和聲引擎　－ 偏欣賞而非修改編

✓
調性色彩流 (key / modulation color) 🎯 建議lane

調中心／轉調用流動色帶呈現 —— 整首的和聲旅程一條看完。

填補：轉調「看得見」。美又有意義（不是 eye-candy，色彩=調性資訊）。

＋ 美感+教育兼具、轉調具象化　－ 調性偵測準度依賴分析品質

✓
弦樂把位流動 (string position flow) 🎯 弦樂lane

左手把位 (1st/3rd/5th…) 沿時間上下移動的軌跡。

填補：看換把在哪、把位跳動大不大。接既有指板模擬 + 指法 DP，弦樂教學超實用。

＋ 弦樂教學超實用、複用指法 DP　－ 只對弦樂 (niche)

✓
旋律輪廓 ribbon (melodic contour) 🤔 中性lane

主旋律音高連續描成一條線，看旋律的拱形／走向。

＋ 看旋律形狀　－ 樂譜本身已表達音高，附加值中等

✓
織體能量流 (texture energy) 🤔 中性lane

同時發聲音數／總能量沿時間的捲動面積圖，看疏密起伏。

＋ 看編配疏密　－ 跟既有難度熱圖部分重疊

我的一句話建議： 先做 聲部音量表 + 音域帶狀圖 + 即時和聲（你已選）。 連續視覺化：先做 流動條基礎元件，再上 和聲張力 + 調性色彩 兩條 lane（弦樂線想推就加把位流動）。 鋼琴捲軸留作大賭注；波型／頻譜跳過。
